# Category Management Dashboard

A full-stack E-commerce Admin Panel for managing product categories. Built with Node.js, Express, React, and Tailwind CSS.

## Features

- **Secure Authentication**: User signup and login using JWT and bcrypt.
- **Dashboard**: View categories in a responsive grid layout.
- **Category Management**:
  - Add new categories with name, item count, and image URL.
  - Edit existing category details.
- **Responsive UI**: Professional design using Tailwind CSS.

## Tech Stack

### Frontend
- React.js (Vite)
- Tailwind CSS
- Axios
- React Router DOM
- Lucide React (Icons)

### Backend
- Node.js
- Express.js
- SQLite (Sequelize ORM)
- JWT & BCrypt

## Local Setup Steps

1. **Clone the repository** (if applicable) or navigate to the project folder.

2. **Backend Setup**:
   ```bash
   cd server
   npm install
   node server.js
   ```
   Server will run on `http://localhost:5000`.

3. **Frontend Setup**:
   Open a new terminal.
   ```bash
   cd client
   npm install
   npm run dev
   ```
   Frontend will run on `http://localhost:5173`.

4. **Usage**:
   - Register a new account.
   - You will be redirected to the Dashboard.
   - Add categories using the "+ Add Category" button.
